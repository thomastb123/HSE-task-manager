# 100% Free GitHub Pages Setup Guide for HSE Task Manager

GitHub Pages is **100% FREE forever** with **no hidden fees or trial limits**. It provides a permanent 24/7 web link that works even when your laptop is turned off!

---

## 🚀 4 Simple Steps to Host on GitHub Pages

### STEP 1: Create a Free GitHub Account
1. Open your browser and go to **[https://github.com](https://github.com)**.
2. Click **Sign Up** (Free).

---

### STEP 2: Create a New Repository
1. Log in to GitHub and click the **`+`** icon at the top-right corner ➔ Select **New repository**.
2. Set the repository details:
   - **Repository name**: `hse-task-manager`
   - **Visibility**: Public
3. Click **Create repository**.

---

### STEP 3: Upload Your Files
1. On your new repository page, click **"uploading an existing file"**.
2. Open your local folder: `a:\Applications developed by me\HSE task manager`.
3. Drag and drop all files & folders (`index.html`, `css`, `js`, `data`, `BPCL Home page.jpg`, `BPCL logo.jpg`) into GitHub.
4. Scroll down and click **Commit changes**.

---

### STEP 4: Turn on GitHub Pages (Enable Your Web Link)
1. In your GitHub repository, click the **⚙️ Settings** tab at the top.
2. On the left sidebar menu, click **Pages**.
3. Under **Build and deployment**:
   - **Source**: Select `Deploy from a branch`
   - **Branch**: Select `main` (or `master`) ➔ Folder: `/ (root)`
4. Click **Save**.

---

## 📧 Your 100% Free Emailable Web Link:

In about 30 seconds, GitHub will display your free live web link:
> **`https://yourusername.github.io/hse-task-manager/`**

You can now copy and email this link to all officers and your Department Head! It will work 24/7, 365 days a year without costing a single penny!
